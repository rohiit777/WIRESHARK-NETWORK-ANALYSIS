# 🦈 Wireshark Network Traffic Analysis & Packet Inspection Lab

A hands-on network security and protocol analysis project inspecting live network conversations across the OSI model using **Wireshark**.

---

## 📌 Project Overview
This project covers packet sniffing, protocol inspection, cleartext vulnerability demonstration, and attack traffic analysis across 7 core domains:
1. Packet Capture Basics
2. ICMP Analysis
3. DNS Query & Response Dissection
4. TCP 3-Way Handshake & Teardown
5. HTTP vs. HTTPS (Cleartext vs. Encrypted)
6. FTP Credential Sniffing
7. Attack Traffic Analysis (Recon & Scans)

---

## 🛠️ Environment & Tools
* **Packet Analyzer:** Wireshark
* **Testing Utilities:** `ping`, `nslookup`/`dig`, `curl`, `nmap`
* **Protocols Inspected:** Ethernet II, ARP, IPv4, ICMP, UDP, DNS, TCP, HTTP, TLS, FTP[cite: 1]

---

## 🔬 Lab Modules & Analysis
### 1. Packet Capture Basics

Demonstrates interface selection, promiscuous mode packet listening, and OSI layer decoding across the 3 main Wireshark panes (Packet List, Packet Details, Packet Bytes).
